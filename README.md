# Сервис-центр

Простое веб-приложение для управления заявками сервисного центра.

## Запуск
1. Установи зависимости: `pip install -r requirements.txt`
2. Запусти: `python app.py`
3. Открой в браузере: `http://localhost:5000`

## Возможности
- Создание заявок (клиент + устройство)
- Изменение статуса (Новая → В работе → Готово)
- Удаление заявок
- Просмотр всех заявок
